PUBLIER SUR GITHUB PAGES (SANS FRAIS)
1. Créer un compte sur https://github.com/
2. Cliquer sur + puis New repository.
3. Nommer le dépôt : best-poulet-meaux
4. Choisir Public, puis Create repository.
5. Ouvrir le dépôt et cliquer Add file > Upload files.
6. Décompresser ce ZIP sur l'ordinateur. Glisser index.html et le dossier assets (pas le dossier parent best-poulet-github) dans l'écran Upload files.
7. Cliquer Commit changes.
8. Dans le dépôt, ouvrir Settings > Pages.
9. Dans Build and deployment, choisir Deploy from a branch.
10. Branch : main ; dossier : /(root) ; cliquer Save.
11. Attendre la publication, puis ouvrir l'adresse affichée dans Settings > Pages. Elle ressemble à https://VOTRE-NOM.github.io/best-poulet-meaux/

POUR MODIFIER PLUS TARD

- Faire les modifications, puis Commit changes.
